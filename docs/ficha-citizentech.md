# Ficha da CitizenTech

1. **Cidadão:** quem é ajudado?
2. **Problema:** qual dor real do dia a dia?
3. **Como funciona:** o caminho do dado, do sensor à visita.
4. **Tecnologias:** ESP32/Wokwi, .NET + PostgreSQL, Expo, XGBoost/Random Forest, VM Linux, Semgrep/Trufflehog + Mistral.
5. **Ecossistema:** quem participa (idoso, família, ACS, UBS, Defesa Civil...).
6. **Impacto medido/ampliado:** o que muda e como mediríamos (declarar o que é hipótese).
