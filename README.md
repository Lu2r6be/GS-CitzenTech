# Termômetro do ACS — GS CitizenTech (FIAP 2026)

Um ESP32 mede o calor dentro da casa de uma pessoa idosa e a API classifica em um semáforo (verde/amarelo/vermelho). O app mostra ao agente comunitário de saúde (ACS) uma fila de visitas, com as casas mais perigosas no topo.
